# 提出前の確認

## レビュー時に見てほしい点

- `README.md`の操作例からPDF管理・手書き・保存を試せます。
- `library-model.js`は親子関係・同名判定・循環移動防止のルール、`storage.js`はID単位のトランザクション処理です。
- `annotations.js`と`pdf-export.js`は編集データとPDFへの埋め込みを分けています。
- `features/upload/`と`hooks/`は既存Appから安全に分離した小さな処理です。画面全体の状態分割は今後の課題として残しています。
- 現行UIはPDF限定です。Office/画像の変換実装はサーバー側に残し、API経由のテストで検証します。サーバーの公開運用は対象外です。AIは認証付きFolioバックエンドを経由し、WSL2でLuna実応答を確認済みです。iPhone実機は未検証です。

## 提出物に含めないもの

`node_modules/`、`dist/`、`.runtime/`、`artifacts/`、テスト結果、Pythonキャッシュ、LibreOfficeロックファイル、`.env`、証明書・署名鍵はGitの除外対象です。空だったCodemagic設定と生成スクリーンショットも削除しました。CIは`.github/workflows/mobile-release-test.yml`を使用します。

履歴に含まれていたロックファイルとPythonキャッシュは今回の作業ツリーから削除しています。履歴自体は書き換えていません。2026-09-29の確認では、Git管理ファイルと到達可能な履歴を対象に秘密鍵ヘッダー・代表的なアクセストークン形式を検索し、該当はありませんでした。パターン検索で検出できない秘密情報がないかは所有者も確認してください。ローカルのビルド用キャッシュや署名資材を提出ZIPへ手動で追加しないでください。

秘密情報が後から見つかった場合は、削除だけでなく失効・再発行を先に行い、必要に応じて共有済み履歴から除去します。
